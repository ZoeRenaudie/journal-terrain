# Ruptures summary — Experiment A

## What LRMoo / FRBRoo cannot express

| Rupture | FRBRoo presupposes | What *Feux pâles* does |
|---|---|---|
| **R1** | Derivation before co-constitution | Catalogue is part of the work, not derived from it |
| **R2** | Documentation stands outside the work | Conservation study participates in the work's existence |
| **R3** | Identifiable actor for F28 | Authorship deliberately indecidable |
| **R4** | Closed time-span for F3_Manifestation | Activation still open in 2024 |

## Pattern

Each alternative tested resolves one rupture and opens another:

| Alternative | Rupture resolved | New rupture introduced |
|---|---|---|
| Proposed mapping | Surfaces all four ruptures explicitly | None resolved |
| A1 Event-centred | R2 partially (acts rather than entities) | Co-constitution between events still unnameable |
| A2 F15_Complex_Work | R1 partially (catalogue as member) | Unified compositional intent presupposed |
| A3 F12_Nomen | R3 partially (name modelled honestly) | R22 still requires stable referent |
| A4 R48_prototype | R4 partially (prototype relation) | Not in FRBRoo standard |

## Conclusion

The accumulated set of failures is the contribution. It maps what a more adequate documentary model for exhibitions would need to accommodate: co-constitutive relationships between expressions, documentation as participation rather than metadata, deliberately indecidable authorship, and non-closed temporalities.
