# Experiment B — Three artefacts: CIDOC-CRM vs OntoExhibit
## Expérimentation B — Trois artefacts : CIDOC-CRM vs OntoExhibit

**English** · [Français](#français)

---

## English

### Hypothesis

Three objects selected from the 96 in *Feux pâles* are mapped against CIDOC-CRM and OntoExhibit. Each object is chosen for the specific type of documentary problem it poses, derived directly from the conservation report (Renaudie 2017, Tome II).

### Epistemic colour system (Tome II, 2017)

| Colour | Status |
|---|---|
| Black | Verified |
| Blue | Uncertain |
| Grey | Missing |
| Strikethrough | Historically valid, now obsolete |

### Artefacts

| File | Artefact | Problem type |
|---|---|---|
| [artefact-01-barcode.md](artefact-01-barcode.md) | ® (barcode), capc 1990 | Distributed and fictive authorship |
| [artefact-04-and-85.md](artefact-04-and-85.md) | *Klappensonnenuhr*, Tucher, 17th c. | Uncertain provenance, unresolved restitution |
| [artefact-04-and-85.md](artefact-04-and-85.md) | *La Collection de M. Venzano* | Fictive person, fictive transaction |

### Three types of rupture identified

| Type | Description |
|---|---|
| **Forced choice** | The model can record the fact but imposes an arbitrary decision the data do not justify |
| **Structural silence** | No class exists for the phenomenon |
| **Flattening** | The model records the fact by erasing the dimension that makes it meaningful |

## Français

### Hypothèse

Trois objets sélectionnés parmi les 96 de *Feux pâles* sont mappés sur CIDOC-CRM et OntoExhibit. Chaque objet est choisi pour le type spécifique de problème documentaire qu'il pose, tiré directement du rapport de conservation (Renaudie 2017, Tome II).

### Trois types de rupture identifiés

| Type | Description |
|---|---|
| **Choix forcé** | Le modèle peut enregistrer le fait mais impose une décision arbitraire que les données ne justifient pas |
| **Silence structurel** | Aucune classe n'existe pour le phénomène |
| **Aplatissement** | Le modèle enregistre le fait en effaçant la dimension qui fait sens |
