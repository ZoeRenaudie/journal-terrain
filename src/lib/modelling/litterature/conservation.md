# État de l'art : Documentation de l'oeuvre complexe

---

**English** · [Français](#français)

---

La problematique qu'on a ce sont que les oeuvres sont souvent considérées comme statique. Heureusement CIDOC CRM est basé sur l'événement. 

Mais il arrive qu'une oeuvre ait différentes manifestations. LMRoo essaye de resoudre ca pour la litterature. DOCAM modele documentaire s'en est servi pour les oeuvres de timebased media en ajoutant "composant".
