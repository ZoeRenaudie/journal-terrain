# Ontological Modelling Experiments for Exhibitions
## Expérimentations de modélisation ontologique pour les expositions

---

**English** · [Français](#français)

---

## English

This section documents a series of ontological modelling experiments conducted as part of doctoral research on exhibition documentation using semantic web technologies. The central case study is *Feux pâles*, organized by the agency © *readymades appartiennent à tout le monde*® at the capcMusée d'art contemporain de Bordeaux (December 1990 – March 1991).

The research does not propose a definitive ontology. It maps the structural limits of existing heritage ontologies when applied to an exhibition that deliberately destabilizes authorship, identity, and temporal boundaries. Each experiment is designed to generate documentary requirements rather than solutions.

### Context

This work was presented at the **Digital Humanities Conference 2026** (Daejeon, Republic of Korea, July 29, 2026), session S027: "Exhibitions as Data: Mapping the Invisible Threads of a Relational and Processual Heritage."

It is part of a doctoral thesis in art history at the Université de Montréal, affiliated with [CIÉCO](https://cieco.co) and the [Ouvroir d'histoire de l'art et de muséologie numériques](https://ouvroir.umontreal.ca).

### Key finding

Every mapping choice is an interpretive act. Each alternative tested here resolves one rupture and opens another. The accumulated set of failures is itself the contribution: it maps what a more adequate documentary model for exhibitions would need to accommodate.

### Three types of rupture identified

| Type | Description |
|---|---|
| **Forced choice** | The model can record the fact but imposes an arbitrary decision the data do not justify |
| **Structural silence** | No class exists for the phenomenon |
| **Flattening** | The model records the fact by erasing the dimension that makes it meaningful |

## Français

Ce dépôt documente une série d'expérimentations de modélisation ontologique conduites dans le cadre d'une recherche doctorale sur la documentation d'exposition par les technologies du web sémantique. Le cas d'étude central est *Feux pâles*, organisée par l'agence © *readymades appartiennent à tout le monde*® au capcMusée d'art contemporain de Bordeaux (décembre 1990 – mars 1991).

La recherche ne propose pas d'ontologie définitive. Elle cartographie les limites structurelles des ontologies patrimoniales existantes lorsqu'elles sont appliquées à une exposition qui déstabilise délibérément l'authorship, l'identité et les frontières temporelles. Chaque expérimentation est conçue pour générer des exigences documentaires plutôt que des solutions.

### Résultat central

Chaque choix de mapping est un acte interprétatif. Chaque alternative testée ici résout une rupture et en ouvre une autre. L'ensemble cumulé des échecs constitue en lui-même la contribution : il cartographie ce qu'un modèle documentaire plus adéquat pour les expositions devrait pouvoir accommoder.

### Trois types de rupture identifiés

| Type | Description |
|---|---|
| **Choix forcé** | Le modèle peut enregistrer le fait mais impose une décision arbitraire que les données ne justifient pas |
| **Silence structurel** | Aucune classe n'existe pour le phénomène |
| **Aplatissement** | Le modèle enregistre le fait en effaçant la dimension qui fait sens |
